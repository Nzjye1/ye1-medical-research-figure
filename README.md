# Ye1 医学科研图片美化与组图

**根据已有结果绘图，整理和美化论文图片。**

- 利用已有分析结果绘制适合的科研图，按需求调整风格。
- 美化单图、组织多面板组图，并结合材料整理图注。
- 按实际材料和需求交付图片、绘图脚本或可调整面板排版的文件；不编造实验结果。

试着说：“根据这份回归结果做一张森林图，再和其他结果图组合成一张论文组图。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-medical-research-figure-skill.zip)，解压后保留完整的 `ye1-medical-research-figure` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-medical-research-figure` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-medical-research-figure/SKILL.md)。
