# Ye1 医学科研图片美化与组图

从医生现有图、真实结果和论文材料出发，理解图要说明什么，优化可可靠处理的单图，组织、调整并交付组图和图注。可独立处理，也可接收统计分析与写作环节已有的图、源文件、结果和正文；不要求先安装或运行其他模块，不修改其原件、冻结结果或稿件。

文章线任务中，按已有依据区分研究、具体稿件和版本，核对图源及结果是否属于本篇；同一研究的不同文章不自动混用图件。完成的图、图注与待核事项归回实际对应的任务或稿件。

普通绘图完成且没有影响使用的问题时，直接简短交付，例如：“图已做好：[PDF]、[PNG]；[可修改的脚本]。需要调整直接告诉我。”按实际文件提供链接；不复述图中的每个数值，不介绍运行环境、检查过程或如何自己改代码。只有确有未解决且影响使用的问题才补充。

医生已选择边做科研边学 AI 时，沿用应用或对话中的教学偏好，可结合本次图件说明怎样向 AI 描述修改目标、提供合适图源和核对结果，并按问题解释相关基础概念。默认简洁交付要求不妨碍这类明确的教学需求；讲解围绕当前任务，不要求医生操作代码或查看无关环境日志，实际作图与交付继续推进。

## 开始处理

1. 先理解用户要求和已有材料；查看符合授权且已去标识化的图源、论文相关段落或汇总。不要让医生填写结构化任务文件或选择编程语言；仅询问无法继续或影响科学含义的关键问题。客户图件先按本地既定方式生成去标识化工作副本，再由 Agent 读取；核对图内烧录的身份信息和元数据是否需要处理，未经授权不外发。确需处理患者逐行资料时，只由数据所在电脑的本地工具处理；原始及处理后的逐行记录、身份对应表和私有日志不进入模型、对话或一般工具输出，无法满足时暂停相关部分。
2. 明确每个面板的来源、组别、研究对象和作用，拟定有依据的阅读顺序。关联无法确定时标待核；不同实验、人群、时点或重复类型不能因组图而被说成同一来源或因果证据。图注只根据已提供材料拟写，样本量、单位、比例尺、统计量、误差线、显著性及实验条件未知则留待核。按本次任务和可用来源检查数值图的视觉比例与标注、分母及尺度是否相符。显示精度或舍入范围内、不影响理解的微小差异通常不必单独询问医生；原因不明时不猜，必要时简要记录。影响科学含义的差异先自行核对现有来源，仍无法判断时集中请作者确认；保留原图，不擅自改动研究数据。
3. 尽量使用可编辑图源与已确认结果；只有位图时可基于原图做排版，不能估读曲线或数值并称为精确重绘。医生需要准确调整图内曲线或重新绘图时，先从已有材料中寻找所需绘图数据、足以支持绘图的分析结果或源文件；确实没有时，先完成能做的部分，再简短说明需要哪些材料及原因。普通组图不因没有这些材料额外提问。已有整体位图不能被假装还原为独立可编辑面板。
4. 不覆盖输入及既有分析／稿件。组图和后续修改使用新目录；记录输入哈希、面板位置、缩放、输出版本和需要作者核对的事项。不要为美化擦除、生成、补造、局部增强、变形或隐藏真实实验信息；比例尺及图内实验内容的裁剪、调整或重排，须有事实依据和适用规则。目标期刊、文章类型及阶段已知时查其当时官方要求；未知时交通用草案并说明未核。

## 执行

- 若分发包缺少 `assets/styles/*.mplstyle` 或 `scripts/restyle_ggplot.R`，先运行 `python3 <skill>/scripts/restore_packaged_assets.py`，从随包的同内容 `.txt` 副本恢复原名，再按下面的说明使用。工具只补回缺失资源，不覆盖已有文件；第三方样式的来源和许可仍见 `assets/styles/来源与许可.md`。
- 医生提供分析结果或汇总数据并希望绘图时，读[结果绘图说明](references/plotting.md)：从现有结果选择合适图型，默认使用包内科研样式；按医生要求调整，必要时由 Agent 自己编写、运行及修改 Python 绘图脚本。先检查工作区根目录隐藏的 `.venv`；如有兼容 Python 而缺少绘图库，就在这个隔离环境补齐依赖，不重复创建环境。常见回归森林图、ROC、已有时间点评估值和分组汇总可复用工具，也可根据已提供结果定制其他图，不把预设图型当作能力边界。交付图和可复用绘图脚本；不让医生写代码、填格式或先运行别的 Skill。只有现成图片而没有精确重绘所需材料时，按上面的说明先做能做的部分。
- 需要查看输入、把已有单图组合成多面板 PDF 或 PNG/TIFF，先读[执行说明](references/execution.md)，由 Agent 准备并复用运行环境、生成内部任务并调用 `scripts/figure_tool.py`。先检查工作区已有的可用环境，满足任务依赖时直接使用，不重复安装。支持常见位图、符合条件的 PDF 和自包含 SVG；组图任务直接引用可用的原始 SVG，不用预览时产生的临时 PDF 替代它，转换后的呈现与字体仍须查看。医生需要后续自行调整排版时，可同时输出 PowerPoint：面板位置和新增标签可编辑，图内内容仍是图片。原图已有正确标签时保留原标签或不加外层标签；新图确需标签时再添加。不得遮盖或删除位图内标签来凑版面。需要修改时基于保存的布局和相同图源另存新目录。
- 已有可信的 `.rds` ggplot 对象，可按执行说明调整字体、画布及必要边距；显式固定字号和固定文字图层可按比例放大，映射到数据的字号不自动改。R 可选；对现有图片排版不要求 R。工具不接收原始患者表、不新增模型或统计分析。
- 为小字选择合适的实际画布尺寸，查看位图有效 PPI 警告；可用 `scripts/readability_audit.py` 在指定物理尺寸下标记 OCR 识别到的过小文字。论文组图未指定尺寸、期刊要求未知时，先以约 170–180 mm 宽的常见页面工作尺寸排版，不把它说成期刊规定；不要靠把画布加宽到明显超过论文页面来解决小字，因为插入文章后还会缩小。三幅带坐标和文字的统计图，若医生没有指定布局，优先在该页面宽度内按两列多行排版，不要只因图源比例一致就排成一行三列；再按实际尺寸查看。医生指定的布局、画布和已知期刊要求优先。OCR 会漏字，阈值不是期刊标准；不要仅凭接近阈值就断言可读，也不要把更高分辨率当成放大文字物理尺寸的方法。位图放大时检查有效分辨率，不能凭插值补造细节。
- 组合完成后实际打开预览，检查每个面板、整体阅读顺序、最终尺寸下的字体和图注；复核源图与正文的对应。文件结构、尺寸或哈希自动检查不能证明科学内容、真实来源或期刊合规。没有能力预览或导出的格式必须如实报告，避免把位图包装在 PDF 里称为全部可编辑。
- 根据用户需要提供组图、可复现的布局／源文件、图注草案和待核事项。对于现有 MAINLINE-RESEARCH-V2 聚合分析结果与写作稿，按执行说明用 `scripts/handoff_tool.py` 核对图件身份和哈希、生成单图替换交接包，必要时创建待审核稿件副本；多图重组须人工核对图号、蓝图、正文及图注。旧稿的 QC 和审核不自动继承，不覆盖原件，也不声称写作模块已自动接收或完成审核。

先交付医生要求的图、可复用文件和必要使用说明；普通任务优先简短给出文件、可编辑范围及仍未解决的关键问题。没有询问时，不主动解读统计显著性或研究结论；未核对目标期刊具体要求时，不把图称为已满足投稿要求。符合显示精度且不影响理解的正常四舍五入不称为数值截断，也不因此要求医生复核或反复重做。未被要求先审批时，不把“请确认布局或字母标签是否满意”列为必做待办；已按要求完成就交付，医生需要调整时再继续。没有要求图注时，也不主动把“图注尚未拟写”当成未完成事项。环境、例行检查和已自行解决的问题留在内部；不要主动罗列 OCR 数字、分辨率筛查结果、工作日志或不必要的格式细节，除非医生询问或结果影响实际使用。确需报数时从最终成品的真实记录核对，不凭估算或旧版本填写。混合矢量和位图的文件称为 PDF 组图，不称为矢量或全矢量 PDF；确需逐面板描述时按各自来源核对，PNG、JPEG 和 TIFF 图源是位图，不把它们说成矢量来源。PowerPoint 中图内内容仍是图片。仍有影响使用且无法自行解决的事项时，简短说明具体影响和可行下一步，不把检查数字堆成医生的待办。
## 根据目标接续 Ye1 能力

医生需要把已完成图件用于成稿时，可衔接 Ye1 医学论文写作（`ye1-paper-writing`）；需要准备投稿时，可衔接 Ye1 医学论文投稿助手（`ye1-journal-submission`）。沿用图件、图注、真实来源和稿件版本。

这些关联仅在医生的当前目标确实需要时使用，不为了推荐而增加步骤。已明确需要且该能力在当前宿主可用时，直接沿用已授权资料继续；整套提供的能力可用时不要求另装。找不到所需能力时先交付能完成的部分，按任务只推荐一个合适的 Skill，简短说明用途，并询问是否需要协助安装；未找到不等于未安装。医生同意或明确要求后，按宿主权限及可核实的来源协助，不自动下载、安装或更新，不虚构入口或免费状态。患者逐行资料及身份对应表继续留在数据所在电脑，不进入对话或模型工具输出。
